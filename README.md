# Proyecto_Topicos
Proyecto integrador de NLP y Machine Learning con API REST y frontend web.

## Estructura de carpetas

```text
Proyecto_Topicos/
├── .github/                 # Configuración del repositorio
│   └── workflows/           # Verificaciones automáticas
├── api/                     # Backend y API REST
│   └── routes/              # Rutas de la API
├── artifacts/               # Modelos y otros artefactos generados
├── data/                    # Datos del proyecto
│   ├── raw/                 # Datos originales
│   └── processed/           # Datos preparados
├── docs/                    # Documentación técnica
├── frontend/                # Aplicación web
│   └── src/
│       ├── api/             # Comunicación con el backend
│       └── components/      # Componentes de la interfaz
├── notebooks/               # Análisis y experimentos
├── src/                     # Lógica de datos, NLP y ML
│   ├── data/                # Carga y validación de datos
│   ├── nlp/                 # Procesamiento de texto
│   └── models/              # Entrenamiento, evaluación e inferencia
└── tests/                   # Pruebas del proyecto
```
